# halo-theme-diary

移植自 [hugo-theme-diary](https://github.com/amazingrise/hugo-theme-diary) 的 Halo 2.x 博客主题，简洁日记风格。

![Halo](https://img.shields.io/badge/Halo-%3E%3D2.0.0-blue) [![License](https://img.shields.io/badge/License-MIT-green)](LICENSE)

---

## 预览

简洁双栏布局，左侧固定导航，右侧内容流，支持深色模式。

---

## 功能特性

- 日记风格双栏布局，移动端响应式
- 深色模式切换（可在设置中禁用）
- 文章页自动生成目录（TOC）
- 归档页按年月分组
- 分类 / 标签页
- KaTeX 数学公式渲染（可选）
- 文章上下篇导航
- 评论插件支持（`halo:comment`）

### 插件适配

| 插件 | 路径 | 应用市场 |
|------|------|----------|
| 瞬间 | `/moments` | [plugin-moments](https://www.halo.run/store/apps/app-SnwWD) |
| 图库 | `/photos` | [plugin-photos](https://www.halo.run/store/apps/app-BmQJW) |
| 友情链接 | `/links` | [plugin-links](https://www.halo.run/store/apps/app-hfbQg) |

---

## 安装

1. 前往 [Releases](../../releases) 下载最新 `.zip`
2. Halo 后台 → 外观 → 主题 → 安装 → 上传 zip
3. 启用主题

---

## 主题设置

| 设置项 | 默认值 | 说明 |
|--------|--------|------|
| 禁用暗黑模式 | `false` | 隐藏深色模式切换按钮 |
| 启用 LaTeX 支持 | `false` | 启用 KaTeX 数学公式渲染 |
