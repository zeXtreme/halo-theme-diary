# Diary — Halo 2.x Theme

A simple and elegant blog theme ported from [hugo-theme-diary](https://github.com/amazingrise/hugo-theme-diary) to [Halo 2.x](https://halo.run).

## Features

- Clean journal-style layout with sidebar
- Dark mode toggle
- Table of Contents for posts
- Archives grouped by year and month
- Categories and tags support
- Reading time display (optional)
- LaTeX / KaTeX support (optional)

## Installation

1. Download `halo-theme-diary-1.0.0.zip`
2. In Halo Console → Themes → Install → upload the zip
3. Activate the theme

## Settings

| Setting | Default | Description |
|---|---|---|
| 禁用暗黑模式 | false | Disable dark mode toggle |
| 显示阅读时间 | true | Show estimated reading time |
| 启用 LaTeX 支持 | false | Enable KaTeX rendering |

## Requirements

- Halo 2.0.0+
